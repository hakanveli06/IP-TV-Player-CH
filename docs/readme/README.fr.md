# H&M Player

[English](../../README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Português](README.pt.md)

H&M Player est un lecteur IPTV conçu pour la télécommande des téléviseurs Samsung Tizen. Il réunit TV en direct, films, séries, AVPlay/HTML5, aperçu des chaînes, EPG, plusieurs comptes et données TMDb facultatives.

Les titres et résumés TMDb suivent la langue de l’application. Les plateformes disponibles suivent la région de contenu choisie séparément. Les noms de chaînes, catégories et textes EPG restent ceux du fournisseur IPTV.

Au premier démarrage, seules la langue et les données du compte Xtream sont demandées. Une clé TMDb personnelle peut ensuite être ajoutée dans **Paramètres → TMDb**; elle est facultative et n’utilise aucune connexion IPTV.
