# H&M Player

[English](../../README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Português](README.pt.md)

H&M Player — IPTV-плеер для телевизоров Samsung Tizen, оптимизированный для управления пультом. Поддерживаются эфирное ТВ, фильмы, сериалы, AVPlay/HTML5, предпросмотр каналов, EPG, несколько учётных записей и дополнительные данные TMDb.

Названия и краткие описания TMDb отображаются на выбранном языке приложения. Доступные платформы определяются отдельно выбранным регионом контента. Названия каналов, категорий и текст EPG остаются в виде, предоставленном IPTV-сервисом.

При первом запуске запрашиваются только язык и данные Xtream. Личный ключ TMDb можно добавить позже в **Настройки → TMDb**; он необязателен и не использует IPTV-подключение.
