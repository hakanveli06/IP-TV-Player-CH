# H&M Player

[English](../../README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Português](README.pt.md)

H&M Player es un reproductor IPTV para televisores Samsung Tizen pensado para el mando a distancia. Incluye TV en directo, películas, series, AVPlay/HTML5, vista previa de canales, EPG, varias cuentas y datos TMDb opcionales.

Los títulos y resúmenes de TMDb siguen el idioma de la aplicación. Las plataformas disponibles corresponden a la región de contenido seleccionada por separado. Los nombres de canales, categorías y textos EPG se muestran tal como los entrega el proveedor IPTV.

El primer inicio solo solicita el idioma y la cuenta Xtream. Después puede añadirse una clave TMDb personal en **Ajustes → TMDb**; es opcional y no consume conexiones IPTV.
