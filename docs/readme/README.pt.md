# H&M Player

[English](../../README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Português](README.pt.md)

H&M Player é um leitor IPTV para televisores Samsung Tizen, concebido para o comando remoto. Inclui TV ao vivo, filmes, séries, AVPlay/HTML5, pré-visualização de canais, EPG, várias contas e dados TMDb opcionais.

Os títulos e resumos do TMDb seguem o idioma da aplicação. As plataformas disponíveis seguem a região de conteúdo escolhida separadamente. Os nomes de canais, categorias e textos EPG são mostrados tal como fornecidos pelo serviço IPTV.

No primeiro arranque são pedidos apenas o idioma e a conta Xtream. Uma chave TMDb pessoal pode ser adicionada depois em **Definições → TMDb**; é opcional e não consome ligações IPTV.
