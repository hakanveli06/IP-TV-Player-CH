# H&M Player

[English](../../README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [Português](README.pt.md)

H&M Player ist ein fernbedienungsoptimierter IPTV-Player für Samsung-Tizen-Fernseher. Er unterstützt Live-TV, Filme und Serien, AVPlay/HTML5, Kanalvorschau, EPG, mehrere Konten sowie optionale TMDb-Daten.

TMDb-Titel und Kurzbeschreibungen folgen der gewählten App-Sprache. Streaminganbieter werden für die separat gewählte Inhaltsregion angezeigt. Sendernamen, Kategorien und EPG-Texte bleiben unverändert, wie sie vom IPTV-Anbieter geliefert werden.

Beim ersten Start werden nur Sprache und Xtream-Konto abgefragt. Ein persönlicher TMDb-Schlüssel kann später unter **Einstellungen → TMDb** hinzugefügt werden; dies ist optional und verbraucht keine IPTV-Verbindung.
