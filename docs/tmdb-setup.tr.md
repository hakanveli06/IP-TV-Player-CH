# H&M Player’da TMDb’yi etkinleştirme

TMDb; puan ve oy sayısı, seçilen dilde başlık ve kısa özet, tür, süre, yaş sınırı, yönetmen/yapımcı, altı başrol oyuncusunun fotoğrafı, yapım şirketi/ülkesi, film bütçesi/gişesi ve seçtiğiniz ülkedeki izleme platformlarını ekler.

TMDb isteğe bağlıdır. IPTV yayınını değiştirmez veya yayın kilidi açmaz; IPTV sağlayıcısıyla iletişim kurmaz ve IPTV bağlantı hakkını tüketmez.

## Anahtar alma

1. [The Movie Database](https://www.themoviedb.org/) hesabı oluşturun veya giriş yapın.
2. [TMDb API ayarlarını](https://www.themoviedb.org/settings/api) açın.
3. Koşulları kabul edip geliştirici API anahtarı oluşturun.
4. 32 karakterli **API Anahtarı** değerini kopyalayın. H&M Player uzun API okuma erişim jetonunu da kabul eder; kısa anahtar TV kumandasıyla daha kolay girilir.
5. **H&M Player → Ayarlar → TMDb** yolunu açın.
6. Anahtarı girip **Kaydet ve test et** seçeneğini kullanın.
7. **İçerik bölgesi** altında yaşadığınız ülkeyi seçin. İzleme platformları bu ülkeye göre gösterilir; arayüz, ses ve altyazı dilinden bağımsızdır.

Anahtar yalnızca TV’de saklanır. Ekran görüntülerinde, hata bildirimlerinde veya Public Git deposunda yayımlamayın.
